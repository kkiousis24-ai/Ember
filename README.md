# Ember

Ember is a modern business finance management platform for professionals and growing teams.

It helps businesses manage their financial activity, budgets, business goals, meetings, team members, reports, and subscription access from one clean dashboard.

## Features

- User registration and authentication
- Transaction management
- Business budgets
- Business goals and progress tracking
- Team members and roles
- Meetings calendar
- Financial reports by category and period
- CSV report export
- 14-day free trial system
- Subscription management
- Greek and English interface
- Light and dark themes
- SQLite database with Entity Framework Core

## Technology Stack

- ASP.NET Core
- .NET 10
- React
- TypeScript
- Vite
- Entity Framework Core
- SQLite
- ASP.NET Core Identity
